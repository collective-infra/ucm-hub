Manual Simulation Operations

Current Mode: Manual SSH Trigger.
The automated web-trigger is currently disabled to prevent API conflicts.

Step 1: Open your terminal and SSH into the UCM-HUB.

Step 2: Navigate to the project directory and activate the environment:

cd /opt/ucm-hub/gis/
source venv/bin/activate

Step 3: Run the 48-hour wildfire plume simulation:

python3 wildfire_sym.py

Step 4: Monitor the progress.

The script will publish to MQTT every 2 seconds. You can switch to the Live Map or Dashboard tabs to see the data populate in real-time.
